# Group B part 7 — the last open i'rab items (Opus, 2026-11-12)

Rule: two named books on the SAME ayah agreeing on one replacement = change.
Sources read from `books_cache/` (al-Jadwal, al-Mujtaba, Darwish, al-Samin,
al-Nahhas, Makki). Applied: `groupb7_fixes.json` (14 edits).

Applied:
- 36:51 «في الصور» نائب فاعل (al-Jadwal + al-Mujtaba); «نفخ» no longer has a hidden na'ib.
- «حتى إذا» → حرف ابتداء at 3:152, 4:6, 7:37, 18:71, 19:75, 23:99, 34:23
  (al-Jadwal + al-Mujtaba on that ayah; Darwish keeps غاية وجر).
- tawkid (al-Jadwal's main reading + al-Mujtaba): 21:64 «أنتم» (tail
  «الظالمون» now خبر «إن»), 26:220 «هو», 41:36 «هو», 76:23 «نحن». 60:5 was part 6.

Kept:
- «حتى إذا» 7:38, 18:74, 18:77: only al-Jadwal on that ayah (al-Mujtaba silent).
  The «حتى» with «غاية وابتداء» wording (10:22, 10:24, 10:90, 11:40, 12:110, 27:18,
  27:84) already includes ابتداء.
- «إنّ + pronoun» elsewhere: al-Jadwal's main reading is فصل or مبتدأ and agrees
  with ours (5:109 rests on al-Jadwal alone; 50:43 al-Jadwal مبتدأ vs al-Mujtaba توكيد).
- 14:29 «وبئس» الواو حالية: al-Jadwal (واو الحال) + Darwish (حالية) = ours.
- 3:143 «فقد» الفاء عاطفة: Darwish = ours; no second book against.
- 64:13 «فليتوكل»: al-Jadwal رابطة, al-Mujtaba زائدة, Darwish عاطفة. No two agree.
