## How the stage-3 changes were kept safe

- **Religious text.** `prefer_single_quotes` rewrote the quoting of
  `hadith_grade_i18n.dart` (the grading glossary). Both maps were compiled
  before and after and compared in Dart: 51 terms and 2 grader names,
  identical keys, values and order.
- **`unawaited_futures` (31).** Each was wrapped in an explicit
  `unawaited(...)` — same behaviour, now stated. One place changed on
  purpose: the clock settings now `await` their `SharedPreferences` write.
- **`avoid_dynamic_calls` (47).** JSON parsing in `official_hijri`,
  `sync_service`, `dorar_check`, `madhahib_section` and `book_text` now
  casts to `Map<String, dynamic>`; a wrong shape still throws where it did.
  Test files that read fixtures keep a file-level ignore with the reason.
- **`cancel_subscriptions` / `close_sinks` (5).** All five are
  process-lifetime singletons, listened once with `??=`; each carries an
  ignore with the reason.
- **Device run (release build, 3.69.1):** home (Hijri date, prayer card),
  a library book opened (pages, printed page, section title), Hajj steps
  and the four-madhhab boxes, the mic listening with 0 errors, and a
  downloaded al-Fatiha (Alafasy, ayah by ayah) played with wifi and data
  OFF — the stage-2 `RecitationSource.localFile` hook is the only route to
  those files. logcat: no Flutter errors.
