- Manifest: no cleartext traffic; exported components are only the launcher activity and audio_service's required media components.
- No secret in the published APKs (v3.59.0, v3.60.0 checked byte-wise).
- Downloads: local copy first; 8 concurrent / 4 per host; partial files detected (size / hash / temp+rename).
