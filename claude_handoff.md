# Rafiq-Al-Darb: Handoff Document & Progress Report

**Date/Time of Handoff:** 2026-08-17
**Application Name:** رفيق الدرب (Rafeeq-Al-Darb)
**Tech Stack:** Flutter, Riverpod, SQLite (`sqflite`), Dio, `path_provider`, `just_audio`

## 1. Project Goal
To build a premium, comprehensive Islamic application merging features from Khatmah, Quran Flash, and Sakeenaty. Core features include:
1. Dual-mode Quran reading (Mushaaf image mode + Text mode)
2. Interactive Digital Misbahah (Sebha)
3. Categorized Azkar with swipeable counters
4. Dynamic Prayer Times with geolocation
5. Advanced Download Manager for bulk offline capabilities

## 2. Completed Implementation (What's Done)

### ✅ Database & Local Storage
- Local SQLite database `quran_local_v2.db` is built and pre-populated using Python scripts.
- Schema includes: `surahs`, `ayahs` (with translations, tafsir, irab, meanings, and page numbers), `azkar`, and `prayer_times`.
- `QuranDbHelper` uses `path_provider` to securely copy the DB from assets into the app documents directory for runtime queries.

### ✅ Architecture & State Management
- **Riverpod** is the state management tool used across the board.
- Global Providers: `quranProvider` (handles text vs mushaaf reading modes), `prayerTimesProvider`, `sebhaProvider`, `downloadManagerProvider`.
- App Shell architecture is in place (`app_shell.dart`), employing an `IndexedStack` to keep all 5 main tabs alive.

### ✅ Core Features & Screens
1. **Home Screen (`home_screen.dart`):** Features the `_PrayerTimesHero` header (counts down to next prayer based on Geolocation and Aladhan API fallback), quick links, daily random Ayah, and Khatmah progress tracker.
2. **Quran Screen (`quran_screen.dart` & `surah_reading_screen.dart`):** Displays a Surah list with both Makki/Madani icons. `SurahReadingScreen` supports dual modes:
   - **Text Mode:** Traditional scrollable text with Tafsir options.
   - **Mushaaf Mode:** Replicates the physical Quran using high-quality PNGs fetched via `DownloadManager`.
3. **Azkar Screen (`azkar_screen.dart` & `azkar_detail_screen.dart`):** Categorized grid of Azkar. The detail screen features a beautifully designed swipeable `PageView` with interactive haptic counters for each Zikr.
4. **Sebha Screen (`sebha_screen.dart`):** Digital rosary featuring a premium animated progress ring, predefined presets, session counters, and haptic feedback.
5. **Downloads Screen (`downloads_screen.dart`):** A centralized dashboard to manage offline assets. Allows downloading the entire 604-page Mushaaf in bulk or downloading specific Surah recitations.

### ✅ Download Manager (`services/download_manager.dart`)
- **Bulk Downloading:** Implemented concurrent bulk download logic to fetch Mushaaf PNG pages from the GitHub source (`Govarjabbar/Quran-PNG`).
- **Audio Downloading:** Logic to fetch MP3 files from CDN (e.g., `server11.mp3quran.net`).
- *Note:* The user specifically requested: "bulk downloads for moshaf or image but not the recieter full audio untill requested explicitly". The implementation honors this — audio is only downloaded per-Surah upon explicit user action from the Downloads tab.
