## Architecture you'll want to know
- **Bottom nav has 7 tabs** (`app/shell/app_shell.dart`, indices in `app/shell/tab_request_provider.dart`): Home, Quran, Prayer(Qibla), Azkar, Tasbeeh, Library, **More** (`AppTab.more = 6`). The **More** tab (`features/more/.../more_screen.dart`) hosts every settings/options screen via a shared `SettingsBody`; there is no settings gear on Home any more.
- **Downloads are two separate engines.** Hadith/books/adhan go through `DownloadManager` (`core/services/download_manager.dart` — Dio streaming to a `.part` file, resume, FIFO queue, foreground service, one aggregated progress notification). **Recitations do NOT use it** — they go through `AyahAudioService` (`core/services/ayah_audio_service.dart`), one MP3 per ayah. That service now **owns** its download state and publishes it through `ValueNotifier`s (`surahJob(edition,surah)` / `fullJob(edition)`), and the whole-reciter loop runs inside the service (survives leaving the Downloads screen). The Downloads UI (`features/downloads/...`) is `ValueListenableBuilder`s over those notifiers.
- **Mushaf** has text editions (real Uthmani reflow from the bundled DB) and **raster** image editions (e.g. the coloured Tajweed mushaf on R2 at `mushaf/tajweed/NNN.jpg`) via `MushafEdition.imagePath/isRaster`. The text reader (`quran_screen.dart` + `mushaf_text_page.dart`) has immersive full-screen (`SystemUiMode.immersiveSticky`) with hybrid auto-scroll (drag pauses, resumes on release), a speed slider, double-tap / floating-button exit, and A±/pinch zoom.
- **Adhan** fires via `flutter_local_notifications` exact alarms; full mode is a **silent** `fullScreenIntent` trigger (category=alarm) that launches `MainActivity` (`showWhenLocked`/`turnScreenOn`) into `AdhanFullScreenScreen`, which owns the audio (just_audio) + synced karaoke subtitles. The `@pragma('vm:entry-point')` background handler powers the Stop/Mute actions. Adhan settings has a **"معاينة الأذان"** card that opens that same player on demand.
- **Splash:** `flutter_native_splash` holds the OS splash (`FlutterNativeSplash.preserve` in `main.dart`) until `SplashScreen` lifts it (`FlutterNativeSplash.remove()`) once the intro video's first frame is painted — no icon-flash. Config lives in `pubspec.yaml`; regenerate native drawables with `dart run flutter_native_splash:create` after any change.
